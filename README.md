# AmesomeWM
Originally based on [Awesome WM Copycats](https://github.com/lcpz/awesome-copycats).

Config uses modular approach of [Modularized AwesomeWM configuration](https://github.com/RobberFox/AwesomeFox).

# Icons & GTK Themes

- [Rosé Pine](https://github.com/rose-pine/gtk)
- [Nord](https://github.com/EliverLara/Nordic)

# Utils
rofi caffeine nitrogen thunnar picom

# Usage:
Uses [GNU Stow](https://www.gnu.org/software/stow/).
```sh
cd ~
git clone https://github.com/GhostOfMe/.dotfiles.git
cd ./.dotfiles
stow awesome 
```
